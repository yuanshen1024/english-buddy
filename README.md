# English Buddy

English Buddy is a static AI English-learning workspace built around
vocabulary, reading, literature, exams, speaking practice and English notes.

## Features

- 8,039 indexed vocabulary entries with exam decks, word forms and review state.
- CET-4, CET-6, IELTS, TOEFL and academic reading materials.
- A 34-title English resource catalogue.
- 20 academic and exam-oriented literature entries.
- English notes, rich-text editing, search, review cards and AI learning tools.
- Responsive desktop, tablet and mobile layouts.

## Project layout

The deployable site lives in `yywz/`. The generated `gh-pages` branch is
published directly by GitHub Pages.

## Local preview

```bash
cd yywz
python3 server/server.py --port 4173
```

Then open `http://127.0.0.1:4173`.

## Content notice

The project stores book and paper metadata plus self-authored learning modules.
It does not include copyrighted book text or full academic papers.
