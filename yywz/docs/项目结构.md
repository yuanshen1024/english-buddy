# English Buddy 项目结构

## 目录分类

```text
yywz/
├── index.html                 # 网站入口，只放页面骨架
├── assets/
│   ├── css/                   # 全站样式、响应式规则与视觉变量
│   ├── data/                  # 生成后的静态词库数据
│   └── js/                    # 页面路由、数据、交互和本地持久化
├── scripts/
│   ├── generate_vocabulary.py # 从公共词典元数据生成规模化词库
│   └── enrich_pronunciation.py# 使用开放 CMUdict 补齐 IPA 音标
├── server/
│   └── server.py              # 支持 /notes 等干净路由的本地服务
└── docs/
    └── 项目结构.md             # 项目说明与后续文件分类规则
```

## 后续文件规则

- 页面入口：放在 `yywz/` 根目录。
- 图片、图标、字体和媒体：放入 `assets/images/`、`assets/icons/` 或
  `assets/fonts/`。
- 样式文件：放入 `assets/css/`。
- 浏览器脚本：放入 `assets/js/`；继续扩展时应按功能拆成独立模块。
- 服务端或本地开发脚本：放入 `server/`。
- 产品说明、设计说明和开发文档：放入 `docs/`。
- 测试脚本和测试数据：分别放入 `tests/` 和 `tests/fixtures/`。

所有资源引用统一从 `yywz/` 作为网站根目录，避免文件移动后出现路径失效。

## 本地运行

在 `yywz/` 目录执行：

```bash
python3 server/server.py --port 4173
```

然后访问 `http://127.0.0.1:4173`。服务端会自动把 `/notes`、
`/exams/mock` 等应用路由返回到 `index.html`。

本项目不依赖 GitHub，也不需要在线上传后才能运行。

## 核心功能区

- 单词工作区：词库管理、搜索、掌握度、单词测试、导入和加入笔记。
- 每日训练中心：单词卡片、图片联想、听音选义、拼写、例句填空、
  发音跟读和间隔复习，训练结果会回写掌握度与复习时间。
- 文献工作区：文献检索、收藏、导入、论文详情、AI 摘要、专业词汇提取、
  阅读题和引用生成。
- 英语书籍与资料库：按词汇、语法写作、经典教材、CET-4、CET-6、
  IELTS、TOEFL、英文原著、非虚构和工具书分类；保存书目与自建学习模块，
  不复制受版权保护的书籍正文。
- 英语笔记：分类、标签、全文搜索、富文本编辑、AI 整理和复习卡片。
- 笔记模板：单词、语法、阅读、错题、作文和课堂笔记模板，以及 AI 总结。
- 功能自检：在“设置”页面运行，检查路由、资源、本地存储和核心数据。

当前内置学习数据：

- 8,039 个跨 CET-4、CET-6、IELTS、TOEFL、高中、考研、GRE、
  口语、商务和学术场景的单词词条。
- 34 本英语书籍、教材、 vocabulary 书目和考试资料。
- 20 篇 CET-4、CET-6、IELTS、TOEFL 和通用学术文献。

## 词库数据

- 生成脚本：`scripts/generate_vocabulary.py`
- 发音补齐：`scripts/enrich_pronunciation.py`
- 静态数据：`assets/data/vocabulary.js`
- 数据来源：ECDICT 公共词典元数据。
- 生成数据只包含单词、音标、词性、中英文释义、标签、来源和考试分类，
  词形变化、词频排名和 IPA 音标，不包含书籍正文或论文全文。

牛津词典通过外部链接查询，不把受版权保护的牛津释义直接打包进网站。
